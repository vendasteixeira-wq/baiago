# Baiago

Painel de turismo para acompanhar chegadas, meios de transporte, status de recepcao e distribuicao operacional em Porto Seguro.

## Como rodar

```bash
npm install
npm run dev
```

Depois acesse `http://127.0.0.1:5173`.

## Scripts

- `npm run dev`: inicia o ambiente local.
- `npm run build`: valida TypeScript e gera a build de producao.
- `npm run preview`: abre a build gerada localmente.
